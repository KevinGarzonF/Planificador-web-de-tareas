Este proyecto es un Administrador de Tareas sencillo pero completo, pensado para que cualquier persona pueda registrar sus pendientes de forma rápida y sin complicaciones. A través de una interfaz limpia y amigable, el usuario puede escribir el título, una descripción y la fecha de su tarea.
